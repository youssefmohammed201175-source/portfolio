# يوسف محمد إسماعيل — هندسة الأثر الرقمي

بورتفوليو شخصي من ثلاثة ملفات فقط، يعمل بلا أي أدوات أو مكتبات خارجية.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | بنية الصفحات والأقسام والنصوص العامة. |
| `style.css` | الألوان والخطوط والمسافات والتجاوب مع الهاتف. |
| `script.js` | البيانات (المشاريع، المهارات، الخدمات، الاقتباسات، التواصل) وكل التفاعلات. |

## كيف تغيّر المحتوى

كل ما تحتاج تعديله موجود في بداية `script.js` داخل الكتلة `CONFIG`:

- `contact` — البريد، واتساب، GitHub، LinkedIn، Facebook. اترك أي حقل فارغًا ولن يظهر رابطه في الموقع.
- `projects` — كل مشروع بعنوانه وحالته (`live` منشور، `demo` تجريبي، `dev` قيد التطوير) ووصفه وتقنياته وروابطه وصورة لقطة الشاشة إن وجدت.
- `skills` — مجموعات المهارات وأسمائها وأيقوناتها.
- `services` — الخدمات بعناوينها ووصفها.
- `quotes` — الاقتباسات التي تتغيّر في الواجهة.
- `aboutPhoto` — مسار صورتك الشخصية؛ اتركه فارغًا لتظهر المساحة البديلة.

النصوص العامة الثابتة (عنوان الافتتاح، أقسام «من أنا»، العناوين) مكتوبة مباشرة داخل `index.html`.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو ارفع المجلد كما هو إلى أي استضافة ثابتة
(GitHub Pages، Netlify، Vercel، أو استضافة عادية). لا حاجة إلى بناء أو تثبيت حزم.

## ملاحظات

- الموقع بالكامل بالعربية ومن اليمين إلى اليسار.
- الأيقونات في قسم المهارات تُسحب من خدمة `simpleicons.org` عند فتح الصفحة؛
  تعمل عند الاتصال بالإنترنت.
- نموذج التواصل يفتح تطبيق البريد أو واتساب برسالة جاهزة، ولا يجمع بيانات ولا يستخدم خادمًا.
- قبل النشر: ضع بريدك ورقم واتساب الحقيقيين في `CONFIG.contact`،
  وأضف صورًا حقيقية للمشاريع بدل المعاينات التصميمية.
